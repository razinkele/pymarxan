## Rulings

- **Unknown-pair message enumerates up to five pairs** (`unknown[:5]`, `; `-joined, `…` when
  truncated) rather than naming only the first: both refuters accept it, the plan's test then
  exercises both bad rows, and the cap keeps a stale table from producing a thousand-entry
  string. Cost if wrong: a longer message.
- **Task 2 stays additive.** The raw-semantics pin `[2,0,0] → 0.0` moves into Task 3's existing
  raw-anchor test; Task 2 keeps assignments whose zone-2 shortfall is invariant under both
  semantics. Not a re-pin: no committed test ever carried the 6.0. Cost if wrong: none.
- **Unlisted contribution pairs are advisory, not errors** (M1): `contribution_gaps()` on the
  model, one `warnings.warn` in `load_zone_project`, `validate()` silent on gaps. This
  **supersedes** the design review's H4 wording ("`validate()` lists missing pairs") and spec
  line 59, both of which conflict with spec line 112 ("advisory"), CLAUDE.md's `validate()`
  contract and the gate consumers. Cost if wrong: a hand-built problem (no loader) never sees
  the advisory unless it calls the method — which is what "advisory" means.
- **`save_zone_project` stays deferred** (R1 stands): unexecuted single-lens API additions do
  not enter a plan at review time; the test helper is deduplicated instead. Cost if wrong: one
  follow-on with its own grounding run.
- **Doc-only citation defects keep HIGH** (H5, H6): VALIDATION.md is the parity record the
  release ships; a false citation there is a false parity claim. Both were verified by the
  synthesis, not merely carried.
- **`make types` runs at Task 2**, not first at Task 5: every typed snippet in the plan was
  probed and passes once `_feature_arrays` is fixed, so the earlier gate adds no surprise.
- **G1 downgraded to MEDIUM** on the refuter's evidence (one-line self-diagnosing NameError, no
  wrong code ships), but its patch is mandatory for Task 1 to run at all.
- **Design-spec patches ride in Task 13 Step 3** (design.md lines 59, 245, 251) so plan, spec and
  VALIDATION.md never disagree on a citation or on the advisory contract.
